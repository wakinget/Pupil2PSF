About

This test suite validates the core functions of Pupil2PSF:

  • Parseval's Theorem: Energy conservation in FFT (sum(|F|²) ≈ sum(|x|²))
  • Non-negativity: Intensity values are ≥ 0
  • NaN/Inf checks: No invalid floating-point values
  • fftshift correctness: DC component properly centered
  • Tone mapping: Monotonic mapping and valid pixel ranges
  • Transmission helpers: Color conversion and legacy compatibility
  • Tool lifecycle: Shape creation with correct transmission values
